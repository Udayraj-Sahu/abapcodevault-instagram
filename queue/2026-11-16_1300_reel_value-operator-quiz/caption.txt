Quick quiz: how do you fill an internal table in a single statement?

Since ABAP 7.40, the VALUE operator builds the whole table inline. Each row goes in its own brackets, so there is no work area and no APPEND.

It also works for structures, nested tables and with BASE to add rows to an existing table.
