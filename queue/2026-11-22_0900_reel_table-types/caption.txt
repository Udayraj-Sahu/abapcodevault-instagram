Stop treating all 3 SAP table types the same.

SAP ABAP tables, Part 3 of 18: transparent table, pooled table, cluster table in the Data Dictionary.

1. Transparent: one SE11 table = one database table, same name and fields
2. Pooled: many small tables stored in one table pool
3. Cluster: related tables stored in one table cluster
4. Example: BSEG sat in cluster RFBLG in ECC; in S/4HANA it is transparent
