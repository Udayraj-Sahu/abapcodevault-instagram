Your SELECT can't find customer 1000? Blame the leading zeros.

SAP ABAP leading zeros bug: the ALPHA conversion routine.

1. KNA1 stores KUNNR as 0000001000, not 1000
2. Screens add the zeros for you, your code doesn't
3. Fix: |{ lv_kunnr ALPHA = IN }| (or CONVERSION_EXIT_ALPHA_INPUT)
4. Then run the SELECT
