Stop guessing why production dumped. Read the dump first.

A 5-step SAP ABAP short dump checklist for ST22:

1. Open ST22, filter by date and user
2. Read the runtime error name (e.g. COMPUTE_INT_ZERODIVIDE)
3. Read the Error analysis section
4. Jump to the source line where it terminated
5. Fix it, then test again
