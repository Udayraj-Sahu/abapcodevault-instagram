SAP ABAP tables, Part 1 of 18: what a database table in SE11 is, and why you need one.

1. An internal table lives only while the program runs
2. A database table is defined in SE11 and its rows stay in the database
3. Activate it and SAP creates the same table in the database
4. Example: the demo table SCARR (AA, AF, LH)
