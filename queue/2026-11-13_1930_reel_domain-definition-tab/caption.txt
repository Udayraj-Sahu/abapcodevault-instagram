You type 1234. SAP stores 0000001234. Why?

Domains, Part 1 of 3: the Definition tab in SE11.

1. Data type and number of characters
2. Decimal places and output length
3. Conversion routine: ALPHA adds leading zeros on input and removes them on output

Classic mistake: SELECT ... WHERE order_no = '1234' finds nothing. Convert with CONVERSION_EXIT_ALPHA_INPUT first.
